## About the Project

**Paint brush holder**: It is 3d printable Holder to hold Paint brush and help to dry without touching other Brush and intermix color.
### User
- Artist 
- Hobbyist painters.

## why i made this?
### My Sister hobby is making painting and while painting she often put the brush on table which make the both table and brush dirty. For solution I make this project
